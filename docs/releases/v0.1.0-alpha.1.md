# Oscillink Safety Ops 0.1.0 alpha 1

**State:** local release-candidate preparation; not published

Oscillink Safety Ops is an independent safety and risk-mitigation supervisor for AI-controlled industrial equipment, connecting machine intent, observed behavior, and safety-manager oversight.

- Package version: `0.1.0a1`
- Intended tag: `v0.1.0-alpha.1`
- Published release: none
- Operational authority: none
- Compliance or certification conclusion: none

## Implemented in this candidate

- Governed exact-byte evidence, provenance, source-change, review, and offline evaluation contracts.
- Deterministic signed runtime configuration, command/state correlation, fail-closed policy,
  persistent intervention latch, and separately authorized recovery transitions.
- Closed-file simulation and replay for a fenced synthetic robot-cell scenario.
- Local simulated one-way protective-stop and inhibit request records. They do not connect to a
  controller or establish that equipment stopped.
- A 36-case project-authored synthetic benchmark and dependency-free read-only static demo.
- Property and adversarial tests, a minimized fuzz-regression corpus, and a finite TLA+ model checked
  by TLC 2.19 using checksum-pinned TLA tools 1.7.4.
