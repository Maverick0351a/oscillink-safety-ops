# Oscillink Safety Ops 0.1.0 alpha 1

**State:** published public prerelease

## Included in this release

- Governed exact-byte evidence, provenance, source-change, review, and offline-evaluation contracts.
- Deterministic signed runtime configuration, command/state correlation, fail-closed policy,
  persistent intervention latch, and separately authorized recovery transitions.
- Closed-file simulation and replay for a fenced synthetic robot-cell scenario.
- Local simulated one-way protective-stop and inhibit request records. They do not connect to a
  controller or establish that equipment stopped.
- A 36-case project-authored synthetic benchmark and dependency-free read-only static monitor.
- Property and adversarial tests, a minimized fuzz-regression corpus, and a finite TLA+ model checked
  by TLC 2.19 using checksum-pinned TLA tools 1.7.4.

## Assurance status and limitations

All benchmark results are synthetic software results. TLA+ is an abstract finite model. Local,
Buildbox, hosted CI, and public readback results are engineering reproduction evidence, not field
evidence, practitioner review, certification, PL/SIL achievement, safe-operation evidence, or
production validation.

The simulated protective-stop and inhibit records do not connect to a controller or establish that
equipment stopped. This software has no machine-control, applicability, certification, or compliance
authority. Real deployment requires application-specific hazard analysis and independently engineered
safety-rated sensors, controllers, communications, and final elements.
